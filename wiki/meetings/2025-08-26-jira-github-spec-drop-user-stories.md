# JIRA↔GitHub spec session — drop user stories, spec from recorded conversation (Aug 26 2025)

**Date:** 2025-08-26 (7:32 PM) · **Attendees:** [[wiki/people/val-levitan.md|Val Levitan]], [[wiki/people/aaron.md|Aaron Bockelie]]. [[raw/Git_JIRA_spec.md]]

A late-evening one-on-one where Val and Aaron argued out the requirement-vs-business-case ordering, Aaron built a top-to-bottom meta-requirements hierarchy (business use case → requirements → capabilities/epics → features → user stories → tasks), and Val concluded **JVL cannot produce real user stories** and should **drop the user-story layer entirely** — replacing it with **AI-interpreted specifications distilled from recorded developer conversations**. This is the "JVL variant" that advances the Aug-22 Spec-Driven Development Process v2.0.
