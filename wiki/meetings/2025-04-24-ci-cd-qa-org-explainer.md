# CI/CD and QA org explainer (2025-04-24)

A short (~13 min) explainer recording on why QA/testing moves *inside* the DevOps development flow — the shift from independent "testers" to embedded **test engineers** who write automated unit and integration tests that live in the Git repo beside the functional code (unit tests → integration tests against a continuously-deployed RGS, hence "CI/CD").
