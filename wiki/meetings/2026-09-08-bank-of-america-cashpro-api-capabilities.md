# Bank of America CashPro — API capabilities for reconciliation and payment initiation

**Date:** September 8, 2026, 12:30–1:05 PM Eastern (~34 min)
**Attendees:** [[wiki/people/val-levitan.md|Val Levitan]], [[wiki/people/nathan-carver.md|Nathan Carver]]; for Bank of America — Brooks Darnell (runs the engagement), Connie Burke (API specialist), Linda Hernandez (JVL's relationship manager), and "Lennon" (account coding; spelling unconfirmed)

A technical review of what Bank of America's APIs can do for JVL. Nathan set out a short-term reconciliation goal (a daily prior-day balance-and-transaction call into Business Central) and a longer-term goal of initiating payments from JVL's own systems; Connie explained that everything runs through CashPro, that there is no API for ACH debits, and that most of her clients end up using APIs for reporting and a NACHA file for payments. Brooks closed with the pricing proposal and the implementation timeline. Val attended as an executive only — "I will not be participating in anything, so I'll be silent in the meeting."
