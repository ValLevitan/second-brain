# GitHub repo organization — archive debate and knowledge federation (Sept 12 2025)

**Sept 12 2025, 12:06pm.** [[wiki/people/val-levitan.md|Val Levitan]], [[wiki/people/pavel.md|Pavel Frolov]], [[wiki/people/aaron.md|Aaron Bockelie]], [[wiki/people/andrey-bosik.md|Andrei Bosik]].

Longest session of the arc. Core debate: [[wiki/people/pavel.md|Pavel]]/[[wiki/people/andrey-bosik.md|Andrei]] wanted a separate **archive organization** for obsolete-but-kept code; Aaron argued GitHub is not a backup strategy — keep code alive or truly archive off-platform — an IT-governance/grooming question (Pavel conceded "as is" for now, to revisit in ~2 years). Also: re-enable Issues/Projects/Discussions that had been disabled; agreed repo merges; **delete the CBSA repo**; and Aaron's **knowledge-federation** model — docs live in each repo's `/docs`, aggregated by a meta "knowledge" repo via git submodules + filter-repo and published with MkDocs/Docusaurus (a git-based Confluence). Also the platform-AWS restructure and the standing SVN/Jenkins split-brain for games/graphics. Undertaking: [[wiki/people/andrey-bosik.md|Andrei]] to produce a written migration plan by Tuesday. Session 3 of the Sept 9→16 arc — substance and dated sequence live on [[wiki/decisions/2025-02-11-github-org-naming-and-structure.md]].
