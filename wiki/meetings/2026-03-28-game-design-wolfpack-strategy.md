- **The Wolfpack clone / parallel-production strategy + the animal-face design principle** — why a *wolf* (broad, front-facing stare like the bison) beats a *stallion* (side/isometric view, works better on horizontal dual-screen); bear rejected (too tall standing); "Wolfpack" naming (IGT owns Wolf Run / Coyote Moon, not Wolfpack; more than two wolves locking in free spins = a pack); the Bally clone lesson (Havana Cubana / Tahitian Queen math-clones cannibalized each other → Wonder Woman Wild/Gold with *different* math forced two-game sales); do not ship three animal-stare-down games in one game-pack; Wolfpack targets South Dakota / Nebraska, NOT the same Georgia release as Twin Bison; the sequence (finish Twin Bison design → get Lena's production schedule *without her knowing* Wolfpack is coming → Michael develops the abstract → introduce it and expedite through concept/design in parallel); Lion's Riches gets the vertical stare-down look but stays a *separate* project (it is #1 in SD, do not destabilize); the floating pay table for dual-screen (frees the second screen; inspired by Bad Dog); submit Wolfpack + Twin Bison to Eclipse together to halve certification cost. → [[wiki/topics/slot-game-design-principles.md]] (Mar-28). - **Val's production-automation vision** — game production as a parallelized "conveyor" (concept / design / production as distinct binary-handoff stages); JVL uses **55 programming languages** ("criminal"), converting toward automation-friendly languages and away from **C** (a prerequisite for entering the HHR market); a live **AI pull-request check** already gates merges at **~$250/month**; meeting-recording→Jira population already tested by Lena; verbalized concepts → 3 comp-art variations "within minutes" and math "within one hour"; the target of short feature branches (200–400 lines) merged into main-as-QA with the ability to release straight to market (vs. the industry 60-day-QA + 60-day-GLI norm); the Texas bug fixed in one day/night, which Val still considers too slow (wants automatic data-collection→fix). → [[wiki/topics/ai-assisted-development.md]] (Mar-28).
