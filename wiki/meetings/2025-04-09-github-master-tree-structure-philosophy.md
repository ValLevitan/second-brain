# Repository "master tree" structure — Val's academic session — Apr 9 2025

Session (~26 min) where [[wiki/people/val-levitan.md|Val]] argues, with [[wiki/people/andrey-bosik.md|Andrei Bosik]] and [[wiki/people/pavel.md|Pavel]], that JVL should adopt a single canonical repository tree — a "**стандарт люкс**" (lux standard) — that opens the same way on every repo, with a README kept current in each directory. Val says he learns this best practice from **Anthropic's Claude 3.7 Sonnet** because it "explains in a human voice," and from **Cline** recursive-memory sessions.

One-line purpose: get the engineers to agree, in principle, to a mandated standard repo tree + a dynamically-maintained README, and to produce an action list.

Substance lands on:

- **Docs-as-code / canonical repo tree + dynamic-README-via-Actions + empty-dir placeholder-file rule + the Unity/Unreal example templates** — [[wiki/topics/docs-as-code-and-atlassian-exit.md]].
- **Val's use of Claude 3.7 Sonnet + Cline recursive-memory + the "Home Renovation" learning analogy** — [[wiki/topics/ai-assisted-development.md]].

The concrete tree was then worked out on Apr 11 — see [[wiki/meetings/2025-04-11-github-repo-template-tree.md]].
