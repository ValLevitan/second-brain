# Software upgrades retail at about $500 a game; close the Ray deal before any partnership talk (Nov 4 2026)

Set by [[wiki/people/val-levitan.md|Val Levitan]] on the [[wiki/meetings/2026-11-04-felipe-sales-coaching-software-upgrade-pricing.md|Nov-4 4:32 PM call]] with [[wiki/people/felipe-miranda.md|Felipe Miranda]] (English), while Felipe prepares a quote for Ray at [[wiki/organizations/inamax-ultra.md|Inamax / Ultra]] that includes "update the software in Georgia" [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]].

## The pricing rule

- **Per game.** Val: "The way I think about upgrades is, I'm thinking $500 per game. So if a game has, sorry, if a release has 15 games, to me it's $7,500… If a release has six games, then it's 3000. If a release has 10 games, it's 5000. It's roughly $500 per game. That's my retail. Price… I'm not talking about cutting deals or whatever it is" [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]].
- **Premium games.** Val: "that's not a premium game. So let's say if I was going to install a Bison game just by itself, I would ask for $1,500. Just the Bison game itself. But let's say a package of six games, I would roughly ask for Three $1000 [$3,000]. This is very, very rough estimate. This is a rule of thumb." Later: "out of the 15, we have two games that by itself, which is Lions and Bisons, which by itself… if I sold it to you now, it would be about $1,500 a game" [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]]. ("Lions and Bisons" = Lion's Riches and Twin Bison — **inference**.)
- **Why: software is the best discount.** Val: "for me, the best form of a discount is software. That's why I'm sticking with $500 a game. And that's why I'm saying a library of brand new 15 games is $7,500. Why am I saying this? Because I'm setting them up for a potential discount on that. Because there is no, there is no bill of material involved in discounting the software." And: "this is a 15 games, 15 brand new games library, 15. This is not a joke" [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]].
- **Where it lands.** Val: "retail price per game is about $500. And I'm pretty sure this is where it's going to land today" [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]].
- **Felipe's own number.** Felipe had been "pushing on, let's define if we can do 2400 for the upgrades", but "I did not say 2400" to Ray — "I say we will charge you for a number" [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]]. Whether that 2,400 is per machine or per package is not said — **unclear**.

## Nail the deal first; partnership later

- Val: "If you make that deal. Then, another step that you could use is you could say, well, how many games do you need for the year?… I would say, would you be interested in us partnering with you? And maybe that would stimulate a conversation. But now that I said it, I want to warn you about something. You may lose the deal. So it's better to nail the deal, get it done. get the machines going, make it perform, and then say, would you like a partner? I'm just opening your horizons at how to sell" [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]]. Felipe: Ray already said "No, I need to test it first" when he tried for more [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]].
- Felipe's aim: "to have a quote they wouldn't say no to, so we could just get it over with, prepare machines, send them out to Nebraska, and start installing those games… I just need to make it happen" [[raw/Meeting_Transcript_Felipe_Sales_Coaching_Software_Upgrade_Pricing-November-4-2026.md]].

## How it sits against earlier pricing

Nov 4 prices a software **upgrade** of installed machines at about $500 a game. Different thing priced; not a contradiction, **inference**.
- **Apr 1 2025:** the Georgia COAM upgrade kit was priced at about $2,900 retail, floor $2,500, on the same "zero bill of material" logic — [[wiki/decisions/2025-04-01-price-georgia-coam-upgrade-kits.md]] (Nov-4 note). Nov 4 prices by game count instead. **Evolution** of the method; the 2025 kit price is not withdrawn on this call.
