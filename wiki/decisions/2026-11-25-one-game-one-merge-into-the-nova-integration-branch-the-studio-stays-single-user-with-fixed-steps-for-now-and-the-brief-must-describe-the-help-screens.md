# One game, one merge; the studio stays single-user for now; help screens go into the brief (Nov 25 2026)

Agreed at the [[wiki/meetings/2026-11-25-nova-standup-four-games-efim-math-and-rk-image.md|Nov 25 2026 NOVA stand-up]] (Russian, 6:19 AM, 33 minutes), led by [[wiki/people/pavel.md|Pavel Frolov]] with [[wiki/people/alexander-biratka.md|Alexander Biratka]], [[wiki/people/igor-metelski.md|Igor Metelski]], [[wiki/people/irina-shishko.md|Irina Shishko]], [[wiki/people/daniil-stauskiy.md|Daniil Stauskiy]], [[wiki/people/evgeny-kharetski.md|Evgeny Kharetski]] and [[wiki/people/anton-leshkevich.md|Anton Leshkevich]] [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]] [[raw/Meeting_Notes_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]]. Val was not present. Context: [[wiki/topics/nova-platform-architecture.md]] and the [[wiki/decisions/2026-11-24-the-studio-bonus-step-is-built-from-templates-now-general-resource-and-scene-steps-come-later-and-lgs-is-to-collect-statistics-into-a-database-on-the-machine-checked-against-gli-11.md|Nov-24 studio ruling]].

*(Quotes come from an unpunctuated Russian speech-to-text transcript, kept word for word; garbles are kept as heard.)*

## 1. MVP 1 needs a game

- **Capabilities.** Biratka made new capabilities from yesterday's meeting, some for the studio and some for LGS, and gave them all the NOVA label; he has not set the release yet — once Daniil and Pavel review theirs, the closed ones can go into MVP 1. Pavel set his own to review; "там все дочерние вроде как закрыты" [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **Why a game.** Biratka: the framework cannot be fully proven without a game — there are requirements "чтобы работал бонус, чтобы правильно насчитывались кредиты в бонусе"; "мы вроде как планировали на MBP один всётаки показать игру." Pavel: "мы можем наверное, показать игру бейс игру." Igor: "у меня у нас готово 4 игры, ну типа с бонусами". Irina: "они ещё не проверены просто, что они есть, крутятся, вертятся" [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].

## 2. Maths for the Georgia games — waiting on Efim

- **Igor.** The games come from Georgia, with three kinds of progression; maths for some "потенциально есть надо ну уточнить у ефима"; "ефим не делал ещё математику для тех матч 3 прогрессив" — the maths must be initialised with the progressive's preset. A week ago Efim said he did not yet have it for NOVA [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **Old maths, not new.** Pavel asked why they wait for new maths; Igor: "это старая математика. Просто ефим не переносил её вот на свой этот дидпроект". Before, Igor's framework asked LGS for the preset and sent it to the maths at start-up; now the maths service lives apart, and "Я получаюсь немного лишним звеном к этому процессе" [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **Remote maths server.** Pavel: can we connect to the remote maths server now? Igor: "Да, если ищем добавить туда, то что надо." Irina wrote to [[wiki/people/efim-podvoiski.md|Efim]] during the meeting — "Мне было сказано на митинге, чтоб я дернула ефима я его дёргаю" [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].

## 3. Igor's games — one game, one merge

- **Status.** Igor finished the four games; they run on a package in his own branch; he merged main into it and the build passes [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **The ruling.** Pavel: into the integration branch "мы сюда засовываем всё подряд"; "Наверно нам стоит сделать, наверное, хотя бы так, что одна играет, однако помирите" (read as "одна игра — один мерж", as in the notes — **inference**). Igor: "Ну да." [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]] [[raw/Meeting_Notes_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]]
- **Repositories.** The old Dragon Pays still sits in the NOVA repository ("donpays… драгон пейс"). "Андрей" created the repositories and Igor uploaded all the games; Kharetski has the links ("Андрей" = [[wiki/people/andrey-bosik.md|Andrey Bosik]] — **inference**) [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **Next: several games and the select screen.** Igor checks how several games run together through the game select screen and profiles memory (unload resources of inactive games), locally first. The select screen changes: designers used to place icon frames on a background because RAGE could not do "ликвид глаз" effects; now the icon with the liquid-glass effect lives in each game's repository — "это точно займусь прям час." Biratka will create a capability if none exists; Pavel found a game-select capability with a feature from Daniil [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].

## 4. Engine, LGS and the RK image

- **Daniil.** Closed one feature and its stories; is on the machine-state feature ("1353") and its stories — "Завтра уже доделаю точно" — then the engine side of showing the screens; in parallel he checks Biratka's capabilities against what the engine already has [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **RAGE into LGS.** A speaker labelled Alexander Biratko, right after Pavel called on Zhenya: "по рейджу там закрыл почти всю джиру"; "Полный перенос… Рэйдж дотацентра в лджс"; questions remain, for example the modem — "мы будем выносить его в отдельный сервис"; the GitHub page was made easier to use; Igor's new games come next; LGS needs changes so match and progressive settings go "ефиму математику без участия игр". **Who spoke is unclear** — the label says Biratka, but the work matches Kharetski's Nov-23 LGS catch-up (**inference**) [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]] [[raw/Meeting_Notes_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **ARM builds.** Pavel: all services now build for ARM. Kharetski: "Да все у нас умеет подаром платформу собираться. Я правда про математику не помню." Pavel: "математику я ж сделал" [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **An RK image with LGS only.** Pavel wants to try an image for RK "даже вот без игр чисто л г с поднять". Kharetski: "ты мне должен предоставить какието вводные данные, чтобы я вбилдер добавил". Pavel works today on whether the system is ready to go into an image; Kharetski: "Ну, значит завтра." Kharetski also said the game select "вообще не работает" when he loads several games [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **How the maths set is built.** Pavel: Efim picks the maths in a committed configuration file and an action builds that set; perhaps a page to pick maths on the fly. Kharetski: better to pick the games and pull their maths in automatically, or simply put all current maths into the image — even with 1,000 games it is not large, and a game could be added later. Pavel: "Согласен, это хороший вариант", but last time there were blockers; it may suit debug builds — "вопрос, как она потом, правда, будет через лаборатории проходить?" Both want a general meeting with Efim [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].

## 5. The studio — single-user, fixed steps, for now

- **Base-game step.** Leshkevich hopes to finish it today. After a brief is imported, all symbols "по умолчанию генерируются процедурно", as are the base-scene components, and can then be redrawn one by one with AI — so the pipeline builds a game that can be played straight away [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **Lock button.** Pavel: the component controls probably lack a lock button, per item or for the group; Leshkevich: "да имеет смысл" [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **Effects — later.** Igor proposed setting a flight effect (point A to point B) with curves in the interface; Pavel: "давайте это, наверное, пока отложим на на будущее будущее улучшательство." Biratka asked more widely how the studio will offer to make such an effect — sprite, video, shader, code animation or Spine; Leshkevich: "хороший вопрос надо я обдумаю"; Pavel: good that it is said — for AI it matters too [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **Parallel work from templates — a future version.** Biratka repeated that the step-by-step process is hard to split — "один человек садится и должен писать игру от начала до конца" — and proposed scenes and resources made from templates, with the brief's plan showing which items are done so several people work in parallel. Pavel: a bonus scene needs a base scene first, for the transition; he named three kinds of transition (independent; using a screenshot of the base game; dependent on the bonus scene). Igor: most are independent; studio projects need a shared format for parallel work. Leshkevich: "Звучит очень здорово для версии, какойнибудь будущей". Pavel: "Пока одна пользовательский режим… С последовательностью шагов." Leshkevich: the strict order makes dependencies easier; generalising now would be "огромный ребил" with no time. Igor: return to it "до этого 15 января условного"; Leshkevich will ask for a backlog item [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]]. This repeats the Nov-24 "templates now, general steps later" outcome.

## 6. Help screens go into the brief

- **The step.** Biratka added a studio step for creating help screens [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **The format.** Igor: help text has symbol substitutions — "этот доллар и. Фигурные скобки" — and text formatting, so whoever writes it must deliver formatted text. Pavel: look at how Lua does string substitution [[raw/Meeting_Transcript_Nova_Standup_Four_Games_Efim_Math_and_RK_Image-November-25-2026.md]].
- **The brief.** Kharetski: "агент спрашивает ровно то, что есть в брифе"; Igor: current briefs only hold line textures for help. Biratka: add a more general help description to the brief — lines, pictures, every bonus — not a fixed page split. Irina: there will be no GDD as such; Pavel and Biratka: it "будет генерироваться на основе на основе брифа". Biratka: "значит тогда в брифи точно нужны описания хпа."
