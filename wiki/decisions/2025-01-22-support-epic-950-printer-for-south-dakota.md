# Support the Transact Epic 950 printer for South Dakota

## What was decided

JVL will add support for the **Transact Epic 950** printer, because it is the #1 printer used in the South Dakota market (followed by FutureLogic / "Paycheck" printers) and operators/locations already know how to service it. Supporting what operators use is treated as a requirement for entering the small SD market. [[raw/sd_vlt_recap-jan-22-2025.md]]

## Related software directives Val approved on the same call

- Rather than ship a FutureLogic **Gen 2** printer to the lab, ship a **USB stick with the (unapproved) software** so Lonnie can start testing sooner — using the regulator's allowance for experimental software. [[raw/sd_vlt_recap-jan-22-2025.md]]
- Find urgently what triggers the erroneous game-shutdown countdown (see [[wiki/projects/south-dakota-vlt-market.md]]). [[raw/sd_vlt_recap-jan-22-2025.md]]
- **Enable CRC validation by default** and fix the swap-bytes on input/output data, so it need not be set each time a machine is configured (Val: "100% agreed"). [[raw/sd_vlt_recap-jan-22-2025.md]]
- **Add an option to lower machine volume to zero** for quiet venues. [[raw/sd_vlt_recap-jan-22-2025.md]]

## Sequencing

- Plan: fix FutureLogic Gen 5 communication and the shutdown message; if fixable quickly, run to GLI for urgent testing/release (~Feb 1) so Lonnie can field-test before he is occupied on Feb 10; ship the Epic 950 support in a second software approval so operators can choose Epic 950 or FutureLogic in the menu. [[raw/sd_vlt_recap-jan-22-2025.md]]
