## 6. Where game mechanics live — left open

- **Anton's question, "самый важный".** Today a small compiled core in Rust ("ядро… написаны на расти, и он такой минимальный") changes rarely, so it is certified once "на долгое время"; many scripts implement the base mechanics [[raw/Meeting_Transcript_NOVA-2_Mechanics_Placement_One_Studio_Tool_and_Game_Metrics-November-11-2026.md]]. His three options:
  1. Keep the core small, mechanics in scripts — but "с каждым новым релизом у нас так большая часть картента, которую нужно будет ресертифицировать".
  2. Move key mechanics into the core — but "Каждый новый релиз так или иначе немножко меняет уже существующие механики", so the core is re-certified again and again.
  3. A flexible mechanics API in the core, designed with an AI agent from his own scanner of free online slot games — "каталог сейчас из 200 игр", e.g. "24 игры холденриспин" (heard; hold and spin) — plus a bare API for wholly new mechanics; after a year or so, proven mechanics from games are promoted into a new core, "раз в полтора года сертифицируем ядро типа версия 2 версия 3". "Я правда я не пробовал" — it needs an experiment [[raw/Meeting_Transcript_NOVA-2_Mechanics_Placement_One_Studio_Tool_and_Game_Metrics-November-11-2026.md]] [[raw/Meeting_Notes_NOVA-2_Mechanics_Placement_One_Studio_Tool_and_Game_Metrics-November-11-2026.md]].
