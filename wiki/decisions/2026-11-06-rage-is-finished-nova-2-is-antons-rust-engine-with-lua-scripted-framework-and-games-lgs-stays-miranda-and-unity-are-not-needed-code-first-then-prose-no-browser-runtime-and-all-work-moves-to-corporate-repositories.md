# Rage is finished; NOVA 2 is Anton's Rust engine with Lua-scripted framework and games; LGS stays; Miranda and Unity are not needed; agile, code first; no browser runtime; everything into corporate repositories (Nov 6 2026, 10:33 AM)

Set at the [[wiki/meetings/2026-11-06-nova2-studio-engine-demo-and-agile-merge-plan.md|Nov 6 2026, 10:33 AM "NOVA-2" merge meeting]] (Russian) — the meeting called at the [[wiki/meetings/2026-11-06-ai-teardown-control-test-aristocrat-mechanic-port-and-trial-game.md|same morning's 8:00 AM teardown review]] to merge [[wiki/people/anton-leshkevich.md|Anton Leshkevich]]'s engine and studio, [[wiki/people/igor-metelski.md|Igor Metelski]]'s scene tools and [[wiki/people/evgeny-kharetski.md|Evgeny Kharetski]]'s design agent into one plan. Present: [[wiki/people/val-levitan.md|Val Levitan]] (host), Leshkevich, [[wiki/people/efim-podvoiski.md|Efim Podvoiski]] (his first time at this series — Val: "Вас на этот митинг пригласили в 1 раз"), Metelski, Kharetski, [[wiki/people/alexander-biratka.md|Alexander Biratka]] (label "Alexander Biratko"), [[wiki/people/pavel.md|Pavel Frolov]], [[wiki/people/irina-shishko.md|Irina Shishko]], [[wiki/people/andrey-bosik.md|Andrey Bosik]] (label "Andrei Bosik") [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]] [[raw/Meeting_Notes_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]]. ## 1. What Anton showed — the engine, the studio and the demo

- **Games as self-contained modules.** Anton recapped the spike: games designed as "самодостаточные модули очень похожи на то, как у нас было в рейдж в фреймворке, где… [они] как плагины"; on Rust a game "состояла из небольшого растфайла, который просто тянул нужные модули из [фреймворка]" plus its own resources, with shared resources such as loading and game select; "после этого… мы договорились, что я напишу реклаймент и кейпа билети. Вот я вчера их составил" — the requirements and capabilities were written the day before (the "NOVA 2" status email read at 8:00 AM) [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]].
- **The architecture.** "У нас есть движок, который имплементирует графику… общения с элджисом [LGS]… gamestate"; "есть 2 репозиторий с фреймворком и играми, и очень большое здесь изменение в том, что игры и [фреймворк] они написаны на лоо скриптах" — Lua scripts — "по одной большой причине, чтобы можно было… Быстро проводить девелопментовские итерации" without recompiling the framework, features and games [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]]. Efim asked what the engine is written in — "На расти" (Rust); the graphics layer was heard as "opensal" / "Опыт джел" — read as OpenGL, as the notes do [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]] [[raw/Meeting_Notes_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]]. The engine executable is in effect a launcher — it "принимает ссылку на [игру]… игры сами по себе они на скриптах написаны… им нужен [энджин]… лаучер по факту" — and the studio links the same engine library [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]].
- **The studio (editor).** A second spike, from an earlier meeting's wish for one place to work with the whole system: "Сам редактор… написан на расте он линкует в движок… Он подключается к i моделям через open раутеры" (OpenRouter) so the model can be switched — "Я для разработки использую… клод хайкву, потому что он очень дешёвый и помогает мне быстро и много вносить изменений" [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]]. A feature can be worked on in isolation — he showed a risk-bet dialog ("алоха риск бета диалог", heard) opened in the editor and changed through chat [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]].
- **MCP and remote control.** Biratka asked whether an outside agent can drive the studio; Anton: "у студии есть MCP сервер и у [фреймворка] есть MCP сервер" — so a console Claude or another model can control it [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]]. - **The demo.** A demo Jira ticket holding assets "для кловр форчу" (Clover Fortune); the platform then held only "калиотчу и dm" (heard — read as Calle Ocho and Dutch Mill, **inference**); the workflow: the agent imports the assets, writes the game, shows it playing, and the person says commit and push [[raw/Meeting_Transcript_NOVA2_Studio_Engine_Demo_and_Agile_Merge_Plan-November-6-2026.md]].
