## 1. What Anton showed — the agent converter

- **The diagram.** [[wiki/people/anton-leshkevich.md|Anton Leshkevich]] showed his Rust application ("приложение да растов" — Pavel). Every box except the leftmost is an agent with its own tools [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]]. The leftmost box, "Interfaces", is Anton and Claude: "Это я и клод." They give tasks to a Builder, which uses the other agents [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]]. The box names read from the shared screen (per the notes): Builder, Scene, Play, RAGE Converter, Art, Game Scripting, Issues, plus Shared tools; app name "Automated Converter" [[raw/Meeting_Notes_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **How it improves.** When an agent finds a gap or a slow tool it logs an issue; after each run Claude, with Anton, reads the logs and issues, fixes the code and rebuilds. "формально не агенты сами себе улучшают, а клод извне улучшает их и пересобирают"; Anton called it "супервайз лординг" (heard; supervised learning). Most of the tool was written by Claude this way [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **Two buttons.** The user has only an autonomous-mode switch (added because the agents kept asking each other for permission) and a pause button [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]] [[raw/Meeting_Notes_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **Val's suggestion.** Add an agent such as a "logwacher или одитор или репортер" (heard) that reports state and can stop the run [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].

- **Step 1 — convert Nebraska games.** Val restated it: "NAD 2, то есть игры для небраска 2 версия, которая написана в rade" (heard; Rage), converted to NOVA. Lions Riches ("лайн Ричард" / "lines Ричарда", heard) is first; "клоп говорит он 16 из 17 задач сделана, но я ещё не запускал новую версию" [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **Step 2 — make the tools general.** Convert "там, скажем, 23 игры" (heard; the notes read it as 2–3 games) [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]] [[raw/Meeting_Notes_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].

[[wiki/people/irina-shishko.md|Irina Shishko]]: then "этот рейс конвектор, он пропадёт вот этот квадратик, а появится новый конвектор с брифдизайном" (heard; RAGE converter); Anton agreed [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **Later boxes.** Autotest, LGS integration, and deploying to the target board [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]] [[raw/Meeting_Notes_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].

## 4. Does NOVA work? The ruling on "done"

- **Val wanted proof.** "Я бы хотел бы подтверждение, что нова работает, потому что для меня это немножко сюрпрайз." Anton: "Так графический движок работает"; games run on Windows, "на р к железя как ещё нет" (heard; RK hardware). [[wiki/people/pavel.md|Pavel Frolov]] once rebuilt Anton's source and "она запустилась на этой 35 76" (RK3576), but "там просто один и тот же ауткам выдавался каждый раз" — no maths [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **The ruling.** Val: "Мы можем собрать только через CICD? Значит там должны быть написаны акшинс, которые собирают, ставят это на продакшн сербер." Then the build is taken from the production server and put into the machine, and the machine starts. "Единственный эталон сделанного" is when a person like him can "взять линк с продакшн сервера", put the file on a USB stick into a machine, and it works [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **Pavel's addition, kept.** A quick local build can show early that performance on the RK board is too low — "мы можем сэкономить там неделю разработки". Val: "то что я сказал не отменяет то что вы сказали Павел"; [[wiki/people/alexander-biratka.md|Alexander Biratka]]: "Не отменяет." Pavel: NOVA works only when all components build into one ISO, even without some parts (for example no progressive controller), installed on a machine or an RK3576 and run in a test mode [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]] [[raw/Meeting_Notes_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].

## 7. LGS — readiness, and the old Data Center dropped

- **Igor's warning.** In Rage, state is saved to the data center synchronously in the main thread: "на одно сохранение может уходить до 8 миллисекунд условно", about half a frame at 60 fps. Threads and sync-vs-async calls must be decided; he asked for a separate agent in the flow for LGS integration, and Anton agreed. "то, что у нас есть движок, это не значит, что у нас есть игра" — the Rage framework is much bigger than its engine [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]]. Pavel: Anton is growing the NOVA framework on top of the engine from the games Claude analyses [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **Dropped: the old Data Center.** Biratka: "Может, будем использовать стар дета центр?" Pavel: "Новый LGS. Он же уже подразумевает, что будет работать с раздельными сервисами девайсов"; Bosik: "модуль на архитектуру"; Kharetski: new interface and API; Igor: "старой дотацентр не общается с математическим сервером никак". Biratka: "Вот ладно всё всё забыли." [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]]
- **Kharetski's direct answer.** "Элджи состояние в том, котором он запустится на машине и будет работать игр у нас нету. И билдера тоже ещё нету. Интеграция с хардварными сервисами не готова", and the hardware services are not yet in the ISO. SAS never connected to it; an autotest platform (contract tests, autotests) is being built in the integration repository. Peripherals work "теоретически и на автотестах", not yet on a machine, because there is no image. LGS works with remote maths; pointing it to local maths is easy. It builds as a Docker container on every pull request and main; the compose file he expected, to run all services on any PC with emulated hardware, does not exist yet [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]] [[raw/Meeting_Notes_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **Pavel's idea.** An "инсталлер, который установит и на старте, запустит все эти сервисы и запустит lg s даже без игры", to check the components on real hardware and walk the setup screens. Not decided [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].

## 9. How the ISO is made, and the Tuesday plan

Pavel: "I so m это отдельный репозиторий интеграционный" (heard; ISO): it takes the game's sources, or a released game artifact, runs tests and packs it; Val added that the maths and LGS go in too [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **Why not now?** Val: "математика в принципе у нас готова", LGS is ready to some degree, and "Антон закончит делать эту нюкин в понедельник у нас будет какаято игра" (heard). [[wiki/people/evgeny-kharetski.md|Evgeny Kharetski]]: "Но я сказал, что элджи с работ будет работать, не сказал, что сборка готова." The missing piece is the actions in the integration repository, to complete its whole cycle. Monday — "Я, я не уверен"; Tuesday — "Может." Val: "давайте во вторник соберём" [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
- **The urgent Georgia work goes on.** Kharetski asked whether everything except the most urgent work moves here; the urgent work is "Б м п один Джорджия" / "Джорджилтеямадем" (heard). Val: "нам нужно алто я мадам. А мы параллельно не можем оба сделать." (heard; per Val after the meeting, recorded in the notes: adapting the LTE mobile modem for the GA-COAM release; the notes read Val's line as "both must be done in parallel") [[raw/Meeting_Transcript_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]] [[raw/Meeting_Notes_NOVA-2_Agent_Converter_Demo_and_First_ISO_by_Tuesday-November-13-2026.md]].
