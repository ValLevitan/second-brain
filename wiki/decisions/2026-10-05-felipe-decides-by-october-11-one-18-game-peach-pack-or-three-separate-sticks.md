# Felipe decides by Oct 11: one 18-game Peach pack or three sticks

> **Status: closed.** **Owner ruling 2026-10-15:** Val said the matter "is done now" and "Felipe's choice is no longer important." The commitment and the reporting question below are closed as moot. How it was settled is not recorded in any source.

Ruled by [[wiki/people/val-levitan.md|Val Levitan]] at the [[wiki/meetings/2026-10-05-ris-mvp1-scope-and-peach-packaging.md|Oct-5 11:00 AM "RIS changes review"]]. Quotations from [[raw/Meeting_Transcript_RIS_MVP1_Scope_and_Peach_Packaging-October-5-2026.md]].

## The idea (Felipe)

Pavel asked which game-pack release would get the new RIS features first. [[wiki/people/felipe-miranda.md|Felipe]]: if JVL can put "one, two, three. 18 games in one pack and just load the RIS… we would be solving another problem of masters… that they have to take either this or that or this USB stick, depending on the version. If we can compact all peach… in one USB stick, that would be phenomenal". It would reach "At least, what, 80% of them? Current machines installed."

## Already possible (Pavel)

[[wiki/people/pavel.md|Pavel]]: "We have one package for 18 games… It's already done; it's supported anytime". "Any set of games can be… organized in… one ISO image."

## Val: it was never written down

Val: the first Peach release had six games; later releases were merged "silently… without sharing with anybody". Felipe corrected the count: "Peach 2 has the 12 games, but Peach 3 is 6 games". Val: Peach 2 had 12 games "because I silently made a decision to include 12 games for lucky bucks… as a specific favor to them. And it was never documented. It was tribal knowledge." Pavel offered a placeholder capability; Val: "which is executed. That capability is closed. But the code, the code needs to be combined." (Lucky Bucks = [[wiki/organizations/arc-gaming.md|ARC Gaming]], former name.)

## The catch: lottery reports (Felipe)

Customers "would like to compare how is Peach Two doing versus Peach One versus Peach Three." The lottery sees one software number per package: "if this is 1919, so 1919 is pitch one, pitch two, the 12 game pack. but… They are not able to tell." "If we have them all packaged in 18, there will be no distinction." Pavel thought the lottery "can produce report related to by games"; Felipe: "I don't know if they get the buy game report. I don't think they do". So: one dongle is better for JVL's technicians, "but for them, I'm not sure." See [[wiki/organizations/georgia-lottery-corporation.md]].

## The ruling

Felipe framed it as a question. Val asked for his recommendation instead: "What do you think we should do?… You tell me how to do it. And you take the ownership of this." Then: "Felipe, you have until the 11th, which is Sunday, to tell me what you want to do… in one release or three separate USB sticks." Felipe: "Clear." Val: "Okay, so that's your undertaking."

## Testing idea (Irina)

[[wiki/people/irina-shishko.md|Irina]], in Russian: build the 18 games "и просто проверить, что каждый отдельный пак рисом устанавливается. То есть в рисе выбрали первые 6" (and simply check that each separate pack installs through RIS — choose the first six in the RIS, and so on).
