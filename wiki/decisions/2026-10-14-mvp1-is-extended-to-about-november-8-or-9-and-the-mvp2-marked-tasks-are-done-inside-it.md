## Which MVP 1 — the RIS improvement MVP 1 (owner-confirmed)

**Owner ruling 2026-10-15:** Val confirmed the reading below — this is the **RIS improvement MVP 1**; the transactional Oct-15 date is unaffected.

The source says only "MVP один". It does not name the product. Four things point to the **RIS improvement MVP 1** (the Georgia branch on the old 1.14 line), not the transactional MVP 1. This is an **inference**:

1. It is said in Kharetski's turn. Kharetski holds the RIS MVP 1 branch (CAP-252, 255, 246, 254) — [[wiki/decisions/2026-10-06-the-ris-mvp1-changes-are-built-for-georgia-only-on-the-1-14-svn-line-with-nothing-else-added.md]]. The battery task 246 he is testing is in that list.
2. "старую версию" (the old version) and "первоначально ты отрезал" (the one you first cut) fit the branch cut from the 1.14 line.
3. The date fits the [[wiki/meetings/2026-10-12-ris-mvp2-scope-and-release-timing.md|Oct-12 RIS MVP 2 call]]: MVP 2 work to about November 1, then about five days at the lab, "So the release would be like November 9th, 10th"; Felipe would be "much happier with all the fixes in Mvp 2" [[raw/Meeting_Transcript_RIS_MVP2_Scope_and_Release_Timing-October-12-2026.md]].
4. In the same stand-up the **transactional** MVP 1 still ends on the 15th. Khamin spoke of a test run "ближе к MP один окончанию"; Pavel: "Куда уже куда уже ближе завтра 15 число." Pavel also spoke of "релизу 15 числа" for the Flex-Port update [[raw/Meeting_Transcript_Daily_Standup_MVP1_Extension_and_RK3576_Game_Library-October-14-2026.md]].

So this source does **not** move the transactional October-15 date ([[wiki/decisions/2026-09-28-october-15-replaces-october-1-as-the-mvp1-date.md]], Oct-14 note). The owner should confirm the reading.
