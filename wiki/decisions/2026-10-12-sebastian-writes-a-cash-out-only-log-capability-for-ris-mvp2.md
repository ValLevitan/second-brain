# A cash-out-only log page goes to Sebastian as an MVP 2 capability

Asked by [[wiki/people/felipe-miranda.md|Felipe Miranda]] and ruled by [[wiki/people/pavel.md|Pavel Frolov]] at the [[wiki/meetings/2026-10-12-ris-mvp2-scope-and-release-timing.md|Oct-12 RIS MVP 2 call]] (English). Quotations from [[raw/Meeting_Transcript_RIS_MVP2_Scope_and_Release_Timing-October-12-2026.md]].

## The request (Felipe)

"It's a cash out only screen, not for Tito, but for ticket cash out, where we see all the cash out logs." Today there is a transaction history "where we see bad win, bad win, deposit, bad, bad win, bad, 81 pages" (bet, win). To find a specific cash-out, staff page "back, back, back. But if they continue playing the machine, this record is overwritten very fast". With "a dedicated window for cash out only, I think 81 pages would be more than enough for anything". "I think this is very important."

Felipe said he had discussed it with [[wiki/people/juan-martinez.md|Juan]] (by context — **inference**), "and Juan told me that it was in progress." [[wiki/people/sebastian.md|Sebastian]]: "No, no." (what he denied is **unclear**).

## The ruling (Pavel)

"Okay, I will ask Sebastian to write down capability related to cash out only page. And we will take a look. I think this is not a big deal to add into Mvp [2]." Sebastian: "Okay." ("Mvp tool" in the transcript; the notes read MVP 2 [[raw/Meeting_Notes_RIS_MVP2_Scope_and_Release_Timing-October-12-2026.md]].)

So: **a capability is written first; it is a candidate for MVP 2, not yet a committed scope item.**

## Oct 20 2026 — the cash-out paragraph is in the release notes and is shown to a customer

- **10:49 AM.** At the [[wiki/meetings/2026-10-20-ris-improvements-release-notes-review.md|release-notes review]] the last paragraph (transaction history) was reviewed. Pavel proposed a filter on the existing transaction screen ("if you selected only a cash out, it will show only cash out"). Felipe: "that doesn't resolve the problem that we have very limited… entries. So in two hours of play, the information that I need from the cash out two hours ago could be deleted." Pavel: "let's left in this written form." [[raw/Meeting_Transcript_RIS_Improvements_Release_Notes_Review-October-20-2026.md]]
- **1:11 PM.** At [[wiki/organizations/diamond-amusement.md|Diamond]] Felipe presented it as "a dedicated tab… for cash out", for cash-outs that are not TITO — "Speaking of the TITO cash outs, tab is already there" [[raw/Meeting_Transcript_Diamond_Amusement_RIS_Improvements_Release_Preview-October-20-2026.md]].

So the page, a candidate on Oct 12, is in the release notes JVL showed a customer on Oct 20 (**evolution**). Which release carries it is not stated. *(On Oct 12 Felipe described it as "not for Tito, but for ticket cash out"; on Oct 20 as not TITO cash-outs, with the TITO tab already there. The two wordings are recorded as spoken.)* Sebastian's capability is not reported written; the commitment stays open. See [[wiki/decisions/2026-10-20-the-ris-improvements-release-notes-are-settled-point-by-point-and-the-tasks-are-to-be-rewritten-to-match-them.md]].
