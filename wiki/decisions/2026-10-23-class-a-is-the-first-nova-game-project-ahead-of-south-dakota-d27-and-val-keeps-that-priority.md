# Class A is the first NOVA game project, ahead of South Dakota D27 (Oct 23 2026)

Confirmed by [[wiki/people/val-levitan.md|Val Levitan]] at the [[wiki/meetings/2026-10-23-game-development-dual-box-rule-and-colombia-class-3.md|Oct 23 2026, 2:00 PM game-development meeting]] (English), on the plan put to him by [[wiki/people/lena.md|Lena Zhukova]] and [[wiki/people/michael-gottlieb.md|Michael Gottlieb]] [[raw/Meeting_Transcript_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]].

## What was said

- **The team asks.** Efim noted that nothing is started on Wild Colt with Match 3 and "it's not even in pipeline because first we have to do class A". Lena: "when we finish Nebraska, we plan to start with Class A project. If we still okay with your plans… we wanted to confirm it." Val: "Yeah, yeah, it's the same, same." [[raw/Meeting_Transcript_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]]
- **Lena's plan.** "our first project in Nova is going to be Class A"; Lions Riches has its design stage "completely done for Class A"; the vertical lines games done for Georgia give symbols and backgrounds to carry over, so it is "a good first project" for graphics, but "on backstage we will have a lot of work to do". Efim: the maths is "totally new". [[raw/Meeting_Transcript_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]]
- **Val checks, and keeps it.** Val asked whether South Dakota D27 is "the first release of Nova or in Nova". Michael: "we were under the impression that Class A was a higher priority. So we were going to put Class A in front of South Dakota D27. But we still have time to make going a different direction." Val: "**No, no, I'm not changing the priority. The priority is fine.**" [[raw/Meeting_Transcript_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]] [[raw/Meeting_Notes_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]]

## Class A status

- **Stage.** Class A is in concept and design stage. Michael: "Class A requirements are done"; Lions Riches "took a while because that was the test bed… The rest of them I can knock out quick." He expects "basically everything in the concept stage done by end of end of next week", and later: "by end of next week… all of the abstracts and the concept stuff for the George Coin Class A, Nova will be complete" ("George Coin" = Georgia COAM, **inference**). Then the focus is "just getting Nebraska done". [[raw/Meeting_Transcript_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]]
- **Storyboard.** Lena's detailed storyboard was shown to Val earlier; he called it "Quite good" [[raw/Meeting_Transcript_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]].
- **A real Liquid Glass shader.** Lena: for Class A the team will make "a shader for Liquid Glass… in a new way for our new framework", done for the first time in this project. Today the effect is "fake"; with the shader the reels can move and change "under this glass dialogue box". Val: "you treat it as a layer, separate layer, right?" Lena: "Yes… That's why we… are going to use semi-transparent dialogue pads." [[raw/Meeting_Transcript_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]]
- **Nebraska keeps the bigger dual box.** Val asked why Nebraska does not use the same see-through selection box. Michael: the Class A look matches "what class A looks like… in that market", while "in Nebraska, our competitors are doing the larger dual box implementation… I think it's actually easier to understand… there's less probability of making a mistake". Both are "market appropriate". No one, Juan included, has called the Nebraska dual box a problem, so "Do no harm." — [[wiki/decisions/2026-10-08-dual-box-for-nebraska-class-a-and-georgia-five-reel-and-no-smaller-touch-area-for-the-wrong-coin.md]] (Oct-23 update) [[raw/Meeting_Transcript_Game_Development_Dual_Box_Rule_and_Colombia_Class_3-October-23-2026.md]]
