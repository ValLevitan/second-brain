## The engine requirements so far (Anton's list)

Anton first ran the existing platforms through AI and collected capabilities from Rage Studio, Rage, NOVA and one more (garbled, "anda") into a framework repository (name garbled), as a toolbox — "чтобы не потерялось… опыт, накопленный за последние там 20, 30 лет", not to carry everything over [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]]. He then went on with the list from the last meeting, with points Sasha and Igor had added [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]]:

- **Screenshots** of full screens, full scenes, or one object [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **Sound in the engine,** so LGS no longer handles it; the current library's licence (name garbled) does not allow casino games out of the box. His recommendation: Kira ("кира"), written in Rust ("написана на раз"), with an MIT licence ("IMIKT лицензия", heard) — "абсолютно бесплатная" [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]] [[raw/Meeting_Notes_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]]. Not formally decided (open question).
- **Video for players — rebuilt from saved round state on a server.** Two options: a buffer of the last seconds of play, uploaded when the player presses a button — a problem for games with up to 400 spins in a round; or save the round data, as game history does, and rebuild. Biratka: a buffer leaves big videos on the machine to upload; saved state is more efficient. Pavel: Daniil did a spike — the state goes to a server-side service that rebuilds the video, so the machine keeps playing and the player gets it on the phone. Anton: "Отлично, ну супер" [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]]. The notes record this as a decision [[raw/Meeting_Notes_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **Shaders from the start.** Biratka: "поддержку шейдеров нам в любом случае надо", even for glass windows; Pixi's shader support was good (a shader on any container) [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **Platforms.** Linux — Bosik asked x86 or ARM; Biratka and Pavel: both; ARM is the RK boards. Windows too, so designers can run games locally. Bosik asked whether a Windows build is still needed; Biratka: Windows is never a final build — "ни в коем случае… чисто… для тестовых наших" [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **WebAssembly — future only.** Not for MVP 1; Anton called it "полёт фантазии" that can be dropped. Bosik and Biratka find full browser support too much; Biratka: trying a recompile costs almost nothing [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **An inspector and an AI API.** A toolkit to inspect scenes, animations and properties; the engine and framework must work well with AI, and the inspector and the AI API use one module — the inspector draws it, the API serves it over the network. Bosik: Unity has MCP support built in; Biratka: first the API, then MCP on top [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **Modularity.** Maths games and bonuses as modules; the game itself a module that is loaded and unloaded. Biratka: "это как бы базовая архитектура"; Bosik: the framework should be "как конструктор" [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **Add resources on the fly.** Kharetski asked about a Unity-style "Play" button. Anton: a full editor is not version 1. Biratka proposed a requirement to add a resource to a scene without reloading it — about half an editor, and it lets AI build scenes live [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **Textured text.** Igor: in Rage the engine cannot put a texture, or even a simple gradient, on text, so such text is made through an atlas or images; the engine must handle it. Anton: "Дайте я запишу себе." Irina: go through the capabilities to see what should move from the framework into the engine [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]].
- **Language: Rust.** Bosik: "на чём ты хочешь всё это писать?" Anton: "Прототип я нарасти написал." (Rust) [[raw/Meeting_Transcript_New_Game_Engine_Requirements_and_Spikes-October-29-2026.md]]
