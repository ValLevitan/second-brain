# Yulia

Yulia (transcribed "Julia") is a **3D artist on JVL's game-design team** under [[wiki/people/lena.md|Lena]]. On the Feb 26 2025 branching-workflow coaching she is the person making the **3D model** within a feature (with [[wiki/people/anastasia.md|Anastasia]] texturing and Lena drawing the Photoshop comp art). [[raw/Evolution_of_Migration_to_GitHub_for_Graphic_designers_2025-02-26.md]]

- Being onboarded to Git / VS Code alongside Anastasia; [[wiki/people/dmitriy-khandov.md|Dima Khandov]] was tasked (Feb 21) with putting "Nastia and Julia" onto GitHub so they could start committing assets, ahead of a Wednesday check-in. Her homework on Feb 26 was to commit her work, merge it back to `main` via pull request, and delete the working branch. See [[wiki/decisions/2025-02-26-designer-branching-workflow.md]]. [[raw/GitHub_commit_of_LFS_demo_by_Lena_2025-02-21.md]] [[raw/Evolution_of_Migration_to_GitHub_for_Graphic_designers_2025-02-26.md]]

- On the Feb 28 Git progress check-in, Yulia (with Anastasia and Lena) was tasked to add the repo-usage rules/documentation into the Fortune Foo Paws repo and keep working through pull requests. See [[wiki/topics/docs-as-code-and-atlassian-exit.md]]. [[raw/Git_progress_check_in_2025-02-28.md]]
