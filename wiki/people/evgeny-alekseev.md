# Evgeny Alekseev

Evgeny Alekseev ("Zhenya Alekseev" / "Женя Алексеев") is a JVL developer who owns the **main code branch** of the FlexPort↔FlexPay embedded software. On the March 11 2025 embedded standup, the other developer ([[wiki/people/evgeny.md|Evgeny]], the integration engineer) said the main branch is "with Zhenya Alekseev" and that he would merge his own branch into Alekseev's to create the common project.
