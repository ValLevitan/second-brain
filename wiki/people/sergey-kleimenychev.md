# Sergey Kleimenychev

Sergey Kleimenychev is a JVL **graphic-design team member** whom Val describes as a **design generalist** — "a little bit of a programmer, a little bit of a designer" — who fits JVL culture well. He was listed on the Minsk staff roster before appearing in any transcript ([[wiki/topics/minsk-staff-roster.md]], as "Kleimenychev Sergey"); he gains this page on his first transcript appearance, the Nov-20 2025 GitHub-for-graphics session. [[raw/application of GitHub for graphic design team.md]]

## Role & standing

- Comfortable on the **command line** and uses Git at home on personal projects — unusual for the art team, most of whom use Git naively through VS Code. He teaches others when he can (also teaches Blender). [[raw/application of GitHub for graphic design team.md]]
- Sits on the far side of a thin office wall from [[wiki/people/andrey-bosik.md|Andrei Bosik]] (DevOps); Val noted the two **don't communicate, respect or trust each other** and convened the Nov-20 call partly to build Sergey's trust in Andrei (who "already knows all the answers"). [[raw/application of GitHub for graphic design team.md]]

## Git / LFS position (Nov 20 2025)

- Initially argued Git is a poor fit for artists — his objection centred on **Git LFS** as a "duct-tape solution" — but conceded there is **no point rolling back** to SVN; the work is to **refine** Git usage. [[raw/application of GitHub for graphic design team.md]]
- Proposed: **reduce the interaction surface** for artists (button-press clone/pull/push via onboarding scripts + aliases), **squash merges** to keep history tidy and allow pruning ~1 GB/day/person of daily renders, and documenting the **stash + LFS** pitfall. [[raw/application of GitHub for graphic design team.md]]
- **Took ownership** of the simplified artist Git-flow "product" — for as long as he works at JVL — to be built with Andrei. Details on [[wiki/topics/graphics-team-git-workflow.md]] and the meeting stub [[wiki/meetings/2025-11-20-github-for-graphic-design-team-git-lfs.md]]. [[raw/application of GitHub for graphic design team.md]]
