# AI-assisted development adoption

JVL's push (led by Aaron) to get the development and QA team using AI coding tools inside a Git-based workflow.

## What happened

- Aaron ran a hands-on workshop for the team (Val, Sasha, Pavel, Andrei, QA) using **VS Code** with **Copilot** and **Cline**, driving **Git** operations and **MCP** (the Model Context Protocol) [[raw/ai-assisted_development_with_vs_code_git_and_mcp_january_14_2025.md]].
- Approach framed as "bootstrapping" (start from nothing) vs. "iterating" on existing code; the AI agent performs Git actions (create branches, edit .gitignore, commit) with the human confirming [[raw/ai-assisted_development_with_vs_code_git_and_mcp_january_14_2025.md]].
- Part of the same rationale as the build-pipeline debate: getting QA comfortable with basic Git so AI tooling can be used effectively [[raw/ai-assisted_development_with_vs_code_git_and_mcp_january_14_2025.md]] [[raw/development_pipeline_january_13_2025.md]].
