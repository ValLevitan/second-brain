# JVL corporate & financial document register

**This register no longer lives in the Second Brain.** By owner ruling (2026-08-03) JVL's corporate **digital identifiers** — Tax IDs / FEINs, state entity IDs, bank account numbers, licence and registration numbers — and the location map of the corporate/financial reference documents that carry them are segregated into their own repository:

- **Corporate Document Register** — `~/Projects/Corporate Document Register/` · private GitHub `ValLevitan/Corporate-Document-Register`.

The Second Brain keeps corporate **knowledge, narrative, maps, charts, and diagrams** (e.g. the [[wiki/organizations/jvl.md|group structure]] and [[wiki/topics/jvl-operating-principles.md|operating principles]]); the binary registry values are held only in the register above. Two source docs that were pure registry content — the JVL Systems and JVL Gameworks *Corporate Identity & Tax IDs* records — were moved into that repository on 2026-08-03.

This stub remains only as a pointer so existing links resolve; it holds no identifiers.
