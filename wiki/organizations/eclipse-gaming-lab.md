# Eclipse (gaming test lab)

Eclipse is a **game-testing/certification lab** JVL uses as an alternative to [[wiki/organizations/gli.md|GLI]]. It appears across JVL's US skill-market work: it is the lab for the [[wiki/projects/georgia-market-rollout.md|Georgia]] Peach submissions, and Val prefers it for [[wiki/projects/nebraska-skill-market.md|Nebraska]] so approvals can run in parallel with Georgia. [[raw/Application_Nudge_Skill_for_Nebraska_2025-03-14.md]]

- On the Mar 14 2025 Nebraska call, Val said he prefers dealing with Eclipse "because I'm hoping to parallel the approvals between Georgia and Nebraska." Because Nebraska's regulations name **GLI**, [[wiki/people/juan-martinez.md|Juan]] is to confirm with the Nebraska Department of Revenue whether Eclipse is an acceptable lab. See [[wiki/decisions/2025-03-14-base-nebraska-on-georgia-conservative-nudge.md]]. [[raw/Application_Nudge_Skill_for_Nebraska_2025-03-14.md]]
- In the same call the lab is also transcribed as **"Xlibs"** ("we already explained it to Xlibs… if you're going through Xlibs") — inferred to be the same Eclipse lab from context; kept as an alias, flagged as unclear. [[raw/Application_Nudge_Skill_for_Nebraska_2025-03-14.md]]

- **≈Mar 19 2025 (date inferred):** with 4–5 releases queued (CPU-Kits, GQAM, "Pitch"-1/2/3 + Vertical, South Dakota VLT, then DLKG), Val ruled that JVL will **pay Eclipse extra for urgent approvals** — "мы не можем позволить себе месяц аппрувл. Это должно неделя, неделя, неделя" (a month per approval is unaffordable; it must be week-by-week). [[raw/products_puerto_rico_touch_fix.md]]

(Earlier Georgia references to the Eclipse lab live on [[wiki/projects/georgia-market-rollout.md]], sourced to the Feb 19 and Mar 7 transcripts.)

## Mar 28 2026 — the partition-signing strategy (SAS-only) that cuts re-certification

On the [[wiki/meetings/2026-03-28-game-design-wolfpack-strategy.md|Mar-28 Wolfpack strategy call]] Val described how JVL had been over-paying Eclipse: Eclipse was signing **all** of JVL's software partitions, but the law only requires the **SAS** partition to be signed. Signing the others created an artificial re-approval trap — whenever a non-regulated partition's checksum changed, Eclipse required re-certification even though that partition never needed signing. JVL's fix: separate the **Omni** system into **7–8 partitions** so that most jurisdictions only sign the legally-required ones, sharply reducing re-approval frequency. [[wiki/people/juan-martinez.md|Juan]] added that Eclipse charges an **extra hour per partition signed**. Val also plans to **submit Wolfpack + Twin Bison together** to halve certification cost (only one math set to prove). §15.8 clear — lab-cost economics only. [[raw/Meeting_Transcript_Game_Design_Wolfpack_Strategy-March-28-2026.md]] [[raw/Meeting_Notes_Game_Design_Wolfpack_Strategy-March-28-2026.md]]
