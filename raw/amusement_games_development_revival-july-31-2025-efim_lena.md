## Summary

This meeting discussed the revival of amusement games development with the following key points:

### Project Scope
- Reviving approximately 150 existing amusement games
- Target platform: Same echo platform (dedicated console)
- Complete redesign required: assets, framework, and programming
- Can reuse game concepts, names, and character designs

### Team Requirements
- **Programmers**: 2 game programmers (passionate and dedicated)
- **Designers**: 1 senior graphic designer + 2 average designers
- **Others**: Sound editor
- Potential candidate: Anton (experienced with these types of games)

### Technical Considerations
- Use existing HTML framework
- Assemble games in Miranda
- Some games require physics engines (already have experience with Monster Truck, etc.)
- Avoid real 3D (new territory)
- Some games may be outdated conceptually

### Timeline Estimates
- 50 games: ~2 years minimum
- 150 games: Significantly longer
- Pace: ~1 game every 2 weeks (optimistic)
- Many simple games (word games, spot-the-difference) but also complex ones

### Challenges
- Competing against Unity-based games, mobile games, and internet games
- Heavy programming workload
- Need passionate developers who can contribute creatively
- Some games require complete reinvention

### Other Considerations
- Outsourcing potential for this project (self-contained, no integration with other products)
- Need to filter which games are worth reviving
- Market positioning concerns

### Administrative Notes
- Team members taking Monday off for holiday
- Vacation planning discussions
